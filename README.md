# 🎮 Connect Four - Cartoon Edition

A fun, modern, and fully responsive Connect Four game built with **HTML, CSS, and JavaScript**. Featuring beautiful cartoon-inspired visuals, smooth animations, customizable player colors, AI opponent support, sound effects, undo functionality, and an engaging mobile-friendly experience.

## 🎲 How To Play

1. Choose a game mode.
2. Enter player names (PvP mode).
3. Customize disc colors.
4. Start the match.
5. Click any column to drop a disc.
6. Connect four discs in a row:

   * Horizontally
   * Vertically
   * Diagonally
7. First player to connect four wins.
